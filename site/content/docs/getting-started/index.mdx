## 1. Installation

### Option A: One-Line Installer (Recommended)

Install the pre-compiled binary release in under 60 seconds across Linux, macOS, and Windows:

```bash
curl -fsSL https://raw.githubusercontent.com/RavaniRoshan/refweir.dev/main/scripts/install.sh | bash
```

The installer script automatically:
1. Detects your operating system (`linux`, `darwin`, `windows`) and architecture (`amd64`, `arm64`).
2. Downloads the official release package with the embedded React 19 Web UI.
3. Verifies the cryptographic SHA-256 checksum against `SHA256SUMS`.
4. Installs `refweird` (forge daemon) and `refweir` (CLI) to `/usr/local/bin` (or `~/.local/bin`).

### Option B: Build from Source

If you prefer building from source, ensure you have **Go 1.22+** and **Git 2.30+**:

```bash
# Clone the repository
git clone https://github.com/RavaniRoshan/refweir.git
cd refweir.dev

# Build the forge daemon (single binary with embedded Web UI, zero CGO)
go build -o bin/refweird ./cmd/refweird

# Build the companion CLI
go build -o bin/refweir ./cmd/refweir
```

## 2. Bootstrap your first administrator

Before launching the server, run the one-time offline bootstrap command to set up the SQLite database and create your root administrative credentials:

```bash
# If installed via 1-line script:
refweird bootstrap \
  --email admin@corp.refweir.dev \
  --namespace acme \
  --data-dir ./data

# Or if built from source:
# ./bin/refweird bootstrap --email admin@corp.refweir.dev --namespace acme --data-dir ./data
```

This command:
1. Applies database migrations to `./data/refweir.db` in SQLite WAL mode.
2. Creates the root namespace (`acme`) and primary administrator user.
3. Outputs an administrative API token (prefixed with `token_`). **Save this token securely.**

## 3. Start the forge daemon

Launch `refweird`:

```bash
# If installed via 1-line script:
refweird

# Or if built from source:
# ./bin/refweird
```

The server binds to port `8080` and is immediately ready to accept Git Smart-HTTP connections, REST requests, and MCP sessions.

### Key service endpoints

| Endpoint | Protocol | Purpose |
| :--- | :--- | :--- |
| `http://localhost:8080/{owner}/{repo}.git` | Git Smart-HTTP | Clone, fetch, and push |
| `ssh://git@localhost:2222/{owner}/{repo}.git` | Pure-Go SSH | Embedded SSH key transport (port 2222) |
| `http://localhost:8080/mcp` | MCP (JSON-RPC) | Autonomous AI agent tools |
| `http://localhost:8080/mcp/readonly` | MCP (JSON-RPC) | Sandboxed read-only MCP endpoint |
| `http://localhost:8080/v1/origin/openapi.yaml` | HTTP | OpenAPI 3.1 specification |
| `http://localhost:8080/healthz` | HTTP | Cluster health & readiness probe |

SCIM 2.0 and SSO are experimental and frozen for launch; the SSO callback fails closed in this build.

## 4. Interactive Onboarding, In-App Manual, & In-Browser Commits

When opening the web console (`http://localhost:8080` in production or `http://localhost:3000` during dev):
1. **Interactive 5-step Onboarding Walkthrough**: Automatically greets first-time administrators, detailing cluster network topology (:8080, :2222, /mcp), git client configuration, and agent leases.
2. **In-App User Manual & System Guide**: Accessible anytime via the **"Manual"** icon in the header, complete with live network port tables and copyable quick-start commands.
3. **Canonical Quick Setup Screen**: When a repository is newly created (0 commits), refweir.dev displays the canonical GitHub Quick Setup screen with HTTPS and SSH command blocks, git push instructions, and agent lease initialization commands.
4. **In-Browser File Creation**: Directly create and commit files (such as `README.md` or `main.go`) directly from the browser using the **"Add file"** button without touching your terminal.
5. **Native SQLite Issues & Comments**: Full issues lifecycle tracking with monotonic numbering, thread commenting, and state transitions backed by SQLite WAL storage.

Configure the `refweir` CLI using your bootstrap API token:

```bash
export REFWEIR_ENDPOINT="http://localhost:8080/v1/origin"
export REFWEIR_TOKEN="<your-admin-token>"
```

### Create and clone a repository

```bash
# Create a new repository in your namespace
./bin/refweir repo create acme/demo-app

# Clone the repository using Git Smart-HTTP
git clone http://localhost:8080/acme/demo-app.git
cd demo-app

# Add a commit and push
echo "# My Demo App" > README.md
git add README.md
git commit -m "feat: initial commit"
git push -u origin main
```

### Create a pull request

```bash
# Create a feature branch
git checkout -b feature/greet
echo "Hello refweir.dev!" >> hello.txt
git add hello.txt
git commit -m "feat: add greeting"
git push origin feature/greet

# Open a pull request with the CLI
./bin/refweir pr create \
  -R acme/demo-app \
  --title "Add greeting feature" \
  --head feature/greet \
  --base main
```

## 5. Connecting AI coding agents via MCP

refweir.dev includes an embedded Model Context Protocol (MCP) server that grants AI coding agents structured access to read trees, inspect diffs, open pull requests, and review code.

Add the refweir.dev MCP server to your agent's configuration file (e.g., Claude Desktop, Cursor, Cline):

```json
{
  "mcpServers": {
    "refweir": {
      "url": "http://localhost:8080/mcp",
      "headers": {
        "Authorization": "Bearer <your-admin-token>"
      }
    }
  }
}
```

:::tip[Read-only sandbox]
For unvetted agents or safety-critical inspection workflows, configure the server URL to `http://localhost:8080/mcp/readonly`. All write operations (`pull_request_create`, `thread_comment`, `pull_request_merge`) will be rejected with an access-denied error at the protocol layer.
:::
