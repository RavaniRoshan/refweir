---
title: Model Context Protocol (MCP) tool catalog
description: Technical reference for the 55 MCP tools exposed by refweir.dev for AI coding agents.
---

refweir.dev natively exposes the Model Context Protocol (MCP) over [JSON-RPC 2.0](https://modelcontextprotocol.io) at `/mcp` (read-write, 55 tools) and `/mcp/readonly` (sandboxed read-only, 25 tools). Run the standard `tools/list` method against `/mcp` for the authoritative tool set in your build.

Every tool call uses standard JSON-RPC 2.0 with method `tools/call`.

---

## 1. Repository & Git Navigation

| Tool Name | Scope | Parameters | Description |
| :--- | :--- | :--- | :--- |
| `get_repository` | Read | `ownerSlug` (string), `repoName` (string) | Get metadata, default branch, and visibility for a repository. |
| `list_repositories` | Read | `ownerSlug` (string, opt) | List repositories accessible to the account across namespaces. |
| `create_repository` | Write | `ownerSlug` (string), `name` (string), `defaultBranch` (string, opt) | Create a new repository in an organization namespace. |
| `get_file_contents` | Read | `ownerSlug` (string), `repoName` (string), `path` (string), `ref` (string, opt) | Read the content of a file blob at a given Git ref (default: `HEAD`). |
| `get_git_tree` | Read | `ownerSlug` (string), `repoName` (string), `ref` (string, opt), `path` (string, opt), `recursive` (bool, opt) | Get the directory tree of a repository at a specified ref. |
| `list_branches` | Read | `ownerSlug` (string), `repoName` (string) | List all branches in the repository with target commit SHAs. |
| `list_commits` | Read | `ownerSlug` (string), `repoName` (string), `ref` (string, opt), `limit` (int, opt) | List commits reachable from a reference. |
| `compare_commits` | Read | `ownerSlug` (string), `repoName` (string), `base` (string), `head` (string) | Compare differences between two commit SHAs or branch refs. |
| `fork_repository` | Write | `ownerSlug` (string), `repoName` (string), `targetNamespace` (string, opt), `forkName` (string, opt) | Fork a repository into an organization or user namespace with lineage tracking. |
| `list_forks` | Read | `ownerSlug` (string), `repoName` (string), `limit` (int, opt) | List repositories forked from a specified parent repository. |
| `sync_mirror` | Write | `ownerSlug` (string), `repoName` (string) | Trigger an immediate sync of a mirrored repository from upstream. |

## Read-Only Sandbox Policy

When connecting to `http://<host>:<port>/mcp/readonly`:
- All **25 Read** tools operate normally and are listed by `tools/list`.
- All **30 Write** tools are filtered out of discovery. Any direct invocation of a write tool immediately returns `isError: true`:
  ```json
  {
    "jsonrpc": "2.0",
    "id": 1,
    "result": {
      "content": [
        {
          "type": "text",
          "text": "Tool 'pull_request_create' is a write operation not permitted on /mcp/readonly"
        }
      ],
      "isError": true
    }
  }
  ```
