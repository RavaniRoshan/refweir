---
title: Command-line interface (CLI) reference
description: Complete command and flag reference for the refweir companion CLI.
---

The `refweir` CLI (`cmd/refweir`) provides terminal and automation access to an refweir.dev instance.

## Installation & Build

```bash
go build -o bin/refweir ./cmd/refweir
```

## Environment Variables

| Variable | Fallback | Description |
| :--- | :--- | :--- |
| `REFWEIR_ENDPOINT` | `http://localhost:8080/api/v1` | Target REST API endpoint URL |
| `REFWEIR_TOKEN` | None | Bearer authentication token |
| `REFWEIR_REPO` | None | Default `owner/repo` used when `-R` flag is omitted |

---

## Global Options

- `--help`, `-h`: Display command usage and available subcommands.
- `--version`, `-v`: Output version string (e.g. `refweir version 2026.10.14`).

---

## Subcommands

### 1. `refweir repo`

Manage repositories within namespaces.

```bash
# Create a new repository
refweir repo create <namespace>/<repo-name> [--description <text>] [--private]

# List repositories in a namespace
refweir repo list [namespace]

# View repository details
refweir repo get <namespace>/<repo-name>

# Fork a repository into an organization or user namespace
refweir repo fork <owner/repo> [--org <namespace>] [--name <new-name>]

# List all forks of a parent repository
refweir repo forks <owner/repo> [--json]

# Synchronize a fork branch from upstream parent
refweir repo sync-fork <owner/repo> [--branch <branch>]

# Delete a repository
refweir repo delete <namespace>/<repo-name>
```

### 2. `refweir pr`

Create, inspect, and merge pull requests.

```bash
# Create a pull request
refweir pr create -R <owner>/<repo> --title <title> --head <branch> --base <target> [--body <description>]

# List pull requests
refweir pr list -R <owner>/<repo> [--state open|closed|all]

# View a pull request
refweir pr view -R <owner>/<repo> <pr-number>

# Merge a pull request
refweir pr merge -R <owner>/<repo> <pr-number> [--merge|--squash] [--commit-message <msg>]

# Close a pull request
refweir pr close -R <owner>/<repo> <pr-number>
```

### 3. `refweir issue`

List, inspect, create, close, and comment on repository issues.

```bash
# List repository issues
refweir issue list -R <owner>/<repo> [--state open|closed|all]

# View an issue and its discussion comments
refweir issue view <number> -R <owner>/<repo>

# Create a new issue
refweir issue create -R <owner>/<repo> --title "<title>" [--body "<description>"]

# Close an issue
refweir issue close <number> -R <owner>/<repo>

# Add a comment to an issue
refweir issue comment <number> -R <owner>/<repo> --body "<comment-text>"
```

### 4. `refweir webhook`

Manage repository webhooks, inspect delivery logs, test endpoints, and redeliver failed payloads.

```bash
# List webhooks configured for a repository
refweir webhook list -R <owner>/<repo> [--json]

# Create a new repository webhook
refweir webhook create -R <owner>/<repo> --url <payload-url> [--secret <secret>] [--events push,pull_request] [--insecure-ssl]

# Test a webhook with a ping payload
refweir webhook ping <webhook-id> -R <owner>/<repo>

# View recent webhook deliveries
refweir webhook deliveries <webhook-id> -R <owner>/<repo>

# Redeliver a past delivery attempt
refweir webhook redeliver <webhook-id> <delivery-id> -R <owner>/<repo>

# Delete a webhook
refweir webhook delete <webhook-id> -R <owner>/<repo>
```

### 5. `refweir auth`

Manage authentication status and credentials.

```bash
# Check current authentication status
refweir auth status

# Login with a token
refweir auth login --token <api-token>

# Logout / clear cached token
refweir auth logout
```

### 6. `refweir app`

Manage apps and installations.

```bash
# List registered apps
refweir app list

# Get app details
refweir app get <app-slug-or-id>
```

### 7. `refweir api`

Execute authenticated HTTP requests against any endpoint of the refweir.dev REST API.

```bash
# GET request
refweir api repos/acme/my-service/pulls

# POST request with JSON payload
refweir api repos/acme/my-service/labels --method POST --body '{"name": "bug", "color": "d73a4a"}'
```

### 8. `refweir lease`

Issue, revoke, and verify cryptographically signed agent capability leases supporting both symmetric HMAC-SHA256 and asymmetric Ed25519 signing.

```bash
# Issue an HMAC-SHA256 capability lease via daemon HTTP endpoint
refweir lease issue --agent agent:worker-1 -R acme/rocket --prefix refs/heads/agent/* --ttl 30m

# Issue an asymmetric Ed25519 capability lease (generates keypair and signs locally)
refweir lease issue --agent agent:builder -R acme/rocket --algorithm ed25519 --ttl 15m

# Issue an Ed25519 lease using a designated private key file
refweir lease issue --agent agent:claude -R acme/rocket --algorithm ed25519 --key-file ~/.refweir/agent_ed25519.key

# Verify an active capability lease token using its Ed25519 public key
refweir lease verify ed25519.ey... --pubkey <base64-or-hex-public-key>

# Verify a capability lease using an HMAC signing secret
refweir lease verify ey... --secret "my-hmac-secret" --json

# Revoke an active capability lease immediately
refweir lease revoke lease_cli_123 --reason "operator manual revocation"
```

### 9. `refweir doctor`

Diagnose daemon connectivity, authentication status, and local environment prerequisites (`git`, `ssh`).

```bash
# Run comprehensive diagnostic check with formatted terminal output
refweir doctor

# Output diagnostic results as JSON for CI/CD or automated scripts
refweir doctor --json
```

### 10. `refweir completion`

Generate shell autocompletion scripts for `bash`, `zsh`, or `fish`.

```bash
# Bash completion (add to ~/.bashrc or source directly)
source <(refweir completion bash)

# Zsh completion (save to a directory in your $fpath)
refweir completion zsh > ~/.zsh/completion/_refweir

# Fish completion
refweir completion fish > ~/.config/fish/completions/refweir.fish
```

### 11. `refweir audit`

Inspect, filter, and stream enterprise compliance audit trails for SIEM integration directly from the terminal.

```bash
# List recent audit events (default limit: 30)
refweir audit list

# Filter audit events by actor and action
refweir audit list --actor alice --action agent.lease_issued --limit 50

# Output audit trail as JSON
refweir audit list --json

# Export audit trail to newline-delimited JSON (NDJSON) for SIEM ingest (Splunk, Datadog)
refweir audit export --since 24h --format ndjson -o audit_24h.ndjson

# Export critical and warning events as CSV for compliance reporting
refweir audit export --severity warning --format csv -o security_audit.csv

# Stream recent audit events as JSON to stdout
refweir audit export --since 7d --format json
```

### 12. `refweir cluster`

Inspect cluster replication health, trigger non-blocking SQLite WAL checkpoints, generate atomic snapshots, and initiate failover promotion.

```bash
# View real-time cluster replication status, active node role, and peer sync
refweir cluster status [--json]

# Trigger an on-demand non-blocking SQLite WAL checkpoint (admin only)
refweir cluster checkpoint

# Capture an atomic VACUUM INTO database snapshot with WAL sequence metadata (admin only)
refweir cluster snapshot [--json]

# Promote a standby replica to cluster primary during planned failover or disaster recovery
refweir cluster promote --yes
```

### 13. `refweir hook`

Run internal Git hook handlers invoked during Git transport operations (such as Smart-HTTP and SSH push enforcement).

```bash
# Execute Git pre-receive verification against standard input ref updates
refweir hook pre-receive
```
