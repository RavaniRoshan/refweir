---
title: Command-line interface (CLI) reference
description: Complete command and flag reference for the refweir companion CLI.
---

The `refweir` CLI (`cmd/refweir`) provides terminal and automation access to an refweir.dev instance.

## Installation & Build

```bash
go build -o bin/refweir ./cmd/refweir
```

## Environment Variables

| Variable | Fallback | Description |
| :--- | :--- | :--- |
| `REFWEIR_ENDPOINT` | `CURSOR_ORIGIN_ENDPOINT`, `http://localhost:8080/v1/origin` | Target REST API endpoint URL |
| `REFWEIR_TOKEN` | `CURSOR_AUTH_TOKEN`, `CURSOR_API_KEY` | Bearer authentication token |
| `REFWEIR_REPO` | `ORIGIN_REPO` | Default `owner/repo` used when `-R` flag is omitted |

---

## Global Options

- `--help`, `-h`: Display command usage and available subcommands.
- `--version`, `-v`: Output version string (e.g. `refweir version 2026.10.14`).

---

## Subcommands

### 1. `refweir repo`

Manage repositories within namespaces.

```bash
# Create a new repository
refweir repo create <namespace>/<repo-name> [--description <text>] [--private]

# List repositories in a namespace
refweir repo list [namespace]

# View repository details
refweir repo get <namespace>/<repo-name>

# Delete a repository
refweir repo delete <namespace>/<repo-name>
```

### 2. `refweir pr`

Create, inspect, and merge pull requests.

```bash
# Create a pull request
refweir pr create -R <owner>/<repo> --title <title> --head <branch> --base <target> [--body <description>]

# List pull requests
refweir pr list -R <owner>/<repo> [--state open|closed|all]

# View a pull request
refweir pr view -R <owner>/<repo> <pr-number>

# Merge a pull request
refweir pr merge -R <owner>/<repo> <pr-number> [--merge|--squash] [--commit-message <msg>]

# Close a pull request
refweir pr close -R <owner>/<repo> <pr-number>
```

### 3. `refweir auth`

Manage authentication status and credentials.

```bash
# Check current authentication status
refweir auth status

# Login with a token
refweir auth login --token <api-token>

# Logout / clear cached token
refweir auth logout
```

### 4. `refweir app`

Manage apps and installations.

```bash
# List registered apps
refweir app list

# Get app details
refweir app get <app-slug-or-id>
```

### 5. `refweir api`

Execute authenticated HTTP requests against any endpoint of the refweir.dev REST API.

```bash
# GET request
refweir api repos/acme/my-service/pulls

# POST request with JSON payload
refweir api repos/acme/my-service/labels --method POST --body '{"name": "bug", "color": "d73a4a"}'
```
