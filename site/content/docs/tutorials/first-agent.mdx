In this tutorial, you will follow an autonomous AI coding agent as it inspects a repository on refweir.dev, analyzes code, and opens a pull request using the Model Context Protocol (MCP).

## What you will learn

- How AI agents discover files and navigate commit trees on refweir.dev.
- How capability leases protect protected branches during agent pushes.
- How agents construct and submit pull requests programmatically.
- How status checks and rulesets gate pull request merges.

## Prerequisites

- `refweird` running locally on port 8080 (`refweird` or `./bin/refweird`).
- A repository initialized in your namespace (e.g., `acme/service`).
- An active administrative token (`token_...`) or an ephemeral capability lease (`lease_...`).

---

## The Scenario

You have instructed an AI coding agent:
> *"Inspect repository acme/service, find main.go, and open a pull request adding a /healthz endpoint."*

Here is how the agent accomplishes this through refweir.dev's MCP server.

---

## Step 1: Inspecting the repository tree

The agent needs to know what files exist in the repository. It calls `repo_tree`:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "repo_tree",
    "arguments": {
      "ownerSlug": "acme",
      "repoName": "service",
      "ref": "main"
    }
  }
}
```

**Response received by the agent:**
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "entries": [
      { "path": "README.md", "type": "blob", "size": 340 },
      { "path": "main.go", "type": "blob", "size": 890 },
      { "path": "go.mod", "type": "blob", "size": 120 }
    ]
  }
}
```

The agent identifies `main.go`.

---

## Step 2: Reading the file content

To understand how to add the endpoint, the agent inspects `main.go` using `file_read`:

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "file_read",
    "arguments": {
      "ownerSlug": "acme",
      "repoName": "service",
      "path": "main.go",
      "ref": "main"
    }
  }
}
```

The agent reads the existing HTTP handlers and decides to add `http.HandleFunc("/healthz", healthHandler)`.

---

## Step 3: Pushing the feature branch

Under refweir.dev's capability lease model, agent credentials are strictly confined to `refs/heads/agent/*`. Attempts to push directly to `main` or arbitrary branches are blocked by the pre-receive hook (`refweir: lease scope denies ref`).

The agent checks out a branch matching its allowed ref prefix:

```bash
git checkout -b agent/health-check
git add main.go
git commit -m "feat: add /healthz endpoint"
git push origin agent/health-check
```

The push is verified by the pre-receive hook, scanned for leaked secrets, and accepted into `refs/heads/agent/health-check`.

---

## Step 4: Opening the pull request

Now the agent opens a formal pull request on refweir.dev using `pull_request_create`:

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "pull_request_create",
    "arguments": {
      "ownerSlug": "acme",
      "repoName": "service",
      "title": "feat: add /healthz health check endpoint",
      "headRef": "agent/health-check",
      "baseRef": "main",
      "body": "This PR adds a lightweight /healthz HTTP liveness probe."
    }
  }
}
```

**Response:**
```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "number": 1,
    "title": "feat: add /healthz health check endpoint",
    "state": "open",
    "mergeable": true
  }
}
```

---

## Step 5: Checking policy & status checks

Before attempting to merge, the agent queries the commit status checks and review suites using `checks_read`:

```json
{
  "jsonrpc": "2.0",
  "id": 4,
  "method": "tools/call",
  "params": {
    "name": "checks_read",
    "arguments": {
      "ownerSlug": "acme",
      "repoName": "service",
      "sha": "9f83a42..."
    }
  }
}
```

If rulesets require passing status checks or peer reviews, the agent inspects the check run states. Once requirements are fulfilled, the PR can be merged via `pull_request_merge`.

---

## Conclusion

You have seen how an autonomous AI coding agent interacts with refweir.dev:
1. Discovers files via `repo_tree` and reads source code via `file_read`.
2. Pushes commits safely within `refs/heads/agent/*` under an ephemeral capability lease.
3. Opens a pull request via `pull_request_create`.
4. Inspects status checks and review gates via `checks_read`.
