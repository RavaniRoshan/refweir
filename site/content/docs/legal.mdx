## Overview

Refweir is an open-source, self-hosted Git forge distributed under the **Apache-2.0** license. This document provides clear, transparent disclosures regarding privacy, cookies, data storage, and terms of use for both the public documentation site and the self-hosted daemon.

---

## 1. Documentation Site Privacy

The public documentation site (`https://ravaniroshan.github.io/refweir/`) is a static site hosted on GitHub Pages.

- **Data Collection:** The Refweir project does not collect, sell, or process personal data, email addresses, or form submissions through this site.
- **Analytics & Tracking:** The documentation site runs zero third-party analytics (no Google Analytics, no Segment, no PostHog, no tracking pixels) and zero session replay tools.
- **Cookies:** The documentation site sets **zero cookies** and does not use local storage for tracking. Theme preferences are handled client-side without transmitting data over the network.
- **Hosting Provider:** GitHub may collect standard HTTP server logs (such as visitor IP addresses) for security and operational purposes pursuant to the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

---

## 2. Self-Hosted Forge Privacy & Data Ownership

When you deploy and run the `refweird` forge daemon on your own infrastructure:

- **100% Data Sovereignty:** All Git repositories, commits, branch heads, pull requests, issues, comments, user accounts, and cryptographic keys reside entirely on your own server or storage volume.
- **Zero Telemetry / Zero Phone-Home:** Refweir contains **no remote telemetry**, no heartbeat pings, and no phone-home mechanisms. Your server does not transmit usage statistics, codebase contents, or symbol indices to external servers.
- **Session Cookies:** The embedded Web UI uses a single, strictly necessary session cookie (`refweir_session`) configured with `HttpOnly`, `SameSite=Lax`, and `Secure` flags. This cookie is used exclusively to maintain your active login session and is exempt from prior-consent requirements under Article 5(3) of the EU ePrivacy Directive.
- **Browser Storage:** The Web UI stores non-sensitive UI state locally in `localStorage` (`refweir_onboarding_tour_completed`, `refweir_sandbox_demo_mode`). This data never leaves your browser.
